# Private ByteBans compatibility probe

This directory contains test infrastructure only. Its plugin and Node client are not part of the releasable ByteBans JAR and must not be uploaded to Modrinth.

Build ByteBans with `mvn install`, then run `mvn -f private-probe/pom.xml package`. The test-only plugin depends on the real ByteBans plugin. On startup it inserts temporary probe punishments, dispatches Bukkit login, chat and movement events for synthetic non-staff and operator players, removes those punishments, and writes `plugins/ByteBansPrivateProbe/results.json`. These checks exercise the live Paper event bus and ByteBans listeners. They do **not** prove that an actual Minecraft client connected.

`matrix.json` pins exact Paper builds, binary SHA-256 hashes and Java runtimes for fifteen Minecraft versions from 1.21 through 26.3, each in online and offline mode. Four of these versions have experimental Paper builds and are labeled as such. `python private-probe/run_matrix.py --list` shows the 30 pinned targets without contacting the server. `python private-probe/run_matrix.py --target paper-1.21.4-online-synthetic` creates one selected isolated server from the pinned pair of JARs, verifies the Paper binary hash, checks the plugin's startup log, reads the JSON result, saves a receipt under `private-probe/runs/`, and stops the server. Use `--jar` and `--source-revision` to bind an exact frozen candidate when the current Maven output has changed. Running without `--target` walks the whole matrix sequentially. The runner preserves every managed instance and world for later inspection. It uses ports 27200–27299, 4 GB RAM and four CPU cores, one server at a time.

For a real protocol check, install the Node client with `npm ci --ignore-scripts` in `private-probe/client/`, then run `python private-probe/run_offline.py`. This creates a separate loopback-bound offline-mode Paper 1.21.4 target and opens an SSH loopback tunnel. Mineflayer joins as two non-operator test users. The script tests actual login, existing-session kick, shared-IP rejection, shared-IP chat mute and freeze/unfreeze movement. A console-only command in the separate testing helper measures the server's authoritative position; Mineflayer's predicted local position is recorded only as context. The script saves its result and stops the server. Use `--reuse <managed-id>` to retest a stopped instance only when its owner, mode, build, port and both JAR hashes match. It never opens the game port on the LAN or internet.

No Microsoft-authenticated bot is available for online-mode protocol login. The online-mode targets therefore use only synthetic event checks; they must be labeled as such. The offline TCP run supplies complementary real-client evidence, but does not by itself establish authenticated-session behavior. Failure or missing results do not imply compatibility.
