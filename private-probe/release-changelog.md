ByteBans 1.1.0 beta adds IP bans and mutes, warnings, staff notes, history lookup, and player freeze/unfreeze commands. New installations use SQLite by default; existing MySQL configurations and punishment records remain supported through a schema migration. Console-only permanent history deletion remains available, and undo actions retain an audit entry.

Optional Discord webhook notifications and a token-protected local admin page are disabled by default. Enabling the webhook sends moderation details, potentially including IP addresses, to the Discord endpoint the server administrator configured. The admin page listens on the server's loopback address and supports moderation actions and history search.

The exact release JAR passed all 30 pinned Paper server probes across 15 Minecraft versions and all 28 pinned Purpur probes across 14 versions, from 1.21 through 26.3. Both online- and offline-mode servers exercised synthetic Bukkit login, chat and movement events. Real offline-mode TCP clients separately checked login, IP bans, IP mutes, freeze and unfreeze on Paper 1.21, 1.21.4 and 1.21.11 and Purpur 1.21 and 1.21.11. The optional admin page passed HTTP and SQLite checks on Paper 1.21.4 and Purpur 26.2. The synthetic online-mode runs did not include an authenticated Minecraft account. Purpur has no build for 26.1.1, so that version is listed for Paper only; Bukkit and Spigot remain unverified for this JAR. Paper builds for 1.21.5, 1.21.9, 26.1.1 and 26.3 are experimental.
